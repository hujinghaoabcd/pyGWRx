# Status and scope

pyGWRx 0.1.0 is an alpha research package. The formal public surface contains 19 supported models plus core numerical, diagnostics, plotting, and I/O namespaces.

Supported means included in the formal project tree, documented, represented by a runnable example, and exercised by the stable suite. It does not mean every model has identical prediction, inference, serialization, or scikit-learn capabilities.
